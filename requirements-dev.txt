#  MovieApp — geliştirme ve test bağımlılıkları
#
#  Bu dosya ÇALIŞMA ZAMANI requirements.txt'i içerir. Yani:
#      pip install -r requirements-dev.txt
#  kurulumu hem API'yi hem testleri çalıştırmak için yeterlidir.
#
#  Docker imajı bu dosyayı KULLANMAZ — build yalnızca requirements.txt okur.
#
#  Neden ayrı?
#  • pytest / pytest-asyncio üretimde gereksiz (~15 MB + bağımlılıkları)
#  • yt-dlp yalnızca Core/Media/MediaHandler.py içinde ALT SÜREÇ olarak
#    çağrılıyor (`yt-dlp` komutu). API bu modülü hiç import etmez; pip
#    paketi yalnızca o komutun binary'sini sağlar.
#  • setuptools / wheel: sdist'ten kurulan paketler için. pip build izolasyonu
#    kullandığından aslında gerekli değildir; eski kurulumlar için tutuluyor.
#  • InquirerPy yalnızca tests/EklentiTestAraci.py (interaktif konsol aracı)
#    tarafından kullanılıyor. Core/Helpers/HTMLHelper.py'deki import'u ölü
#    koddu ve kaldırıldı — API çalışırken TTY olmadığı için orada da
#    kullanılamaz. Zincir ~9 MB (prompt_toolkit + pygments + wcwidth).
#  • playwright + playwright-stealth: 104 MB. İmajın %59'u. Tarayıcı binary'si
#    ayrıca `playwright install chromium` ile (~400 MB) ve HTMLHelper
#    `headless=False` kullandığı için container'da çalışmaz. Yalnızca yerelde
#    Cloudflare Turnstile challenge çözmek isteyenler için.
# ══════════════════════════════════════════════════════════════════════════════

-r requirements.txt

playwright
