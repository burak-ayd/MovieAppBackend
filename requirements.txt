# ── Playwright (opsiyonel, Cloudflare challenge) ─────────────────────────────
# Core/Helpers/HTMLHelper.py yalnızca Cloudflare Turnstile challenge tespit
# edildiğinde tarayıcı açar. İki not:
#
#   1) import MODÜL SEVİYESİNDE olduğu için kurulu olmazsa
#      `import api.app` çöker → container hiç açılmaz. Bu yüzden burada.
#   2) Tarayıcı BİNARYSİ (~400 MB) pip ile kurulmaz; `playwright install
#      chromium` gerekir ve Dockerfile'da YOK. Core/Helpers/HTMLHelper.py
#      bu durumu yakalar: düz HTTP yanıtı varsa onu döndürür, challenge
#      çözülemezse hata verir. Yani bu paket "challenge varsa işe yarar,
#      yoksa düz HTTP'ye düşer" modunda çalışır.
#      Eklenmesi gerekiyorsa Dockerfile'a:
#          RUN playwright install --with-deps chromium
playwright
playwright-stealth
